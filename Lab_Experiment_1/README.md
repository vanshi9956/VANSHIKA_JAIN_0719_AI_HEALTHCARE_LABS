
AI in Healthcare Labs

This repo has my lab work for AI in Healthcare (CSET343) subject.

About

In this lab we had to make a program that can read different types of data - tabular, text, image and signal data, and also medical data. I did it in Google Colab.

What I did in Lab 1
Used the Heart Disease dataset (UCI) and cleaned it, then trained a simple logistic regression model on it
Used real ECG signal data from MIT-BIH dataset and plotted it
Took a sample clinical note and did some basic text processing on it
Made a synthetic image and resized it (used synthetic since real X-ray file was not given)
Wrote a small paragraph at the end about how all these types of data can be combined together
How to run
Open the .ipynb file in Google Colab
Run all the cells one by one (Runtime -> Run all)
Some cells need internet to download data (heart disease csv and ECG data), so make sure Colab is connected
